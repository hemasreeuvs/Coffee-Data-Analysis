# Coffee-Data-Analysis

# Summary of the Project

This project focused on analyzing coffee sales data using Advanced Excel for visualization and Power Query for data cleaning. The goal was to track sales trends, identify key performance metrics, and provide actionable insights.

#Key Aspects of the Analysis:

1. **Data Cleaning & Preparation:**

Used Power Query to clean, structure, and transform the raw sales data for accurate analysis.

Removed inconsistencies, handled missing values, and ensured data integrity.

2. **Sales Performance Analysis:**

Total Sales Over Time: Examined trends in coffee sales from 2019 to 2024 to understand growth patterns.

Sales by Country: Identified top-performing regions based on revenue contribution.

Sales by Roast Type & Size: Analyzed how different roast types (light, medium, dark) and packaging sizes influenced sales performance.

3. **Visualization & Insights:**

Created interactive dashboards using Pivot Tables, Pivot Charts, and Slicers to allow dynamic filtering.

Designed line charts, bar graphs, and heatmaps to represent sales trends effectively.

Discovered key insights, such as the best-selling coffee type, peak sales periods, and regional preferences.

**This project provides a comprehensive overview of coffee sales trends, helping businesses optimize product offerings and marketing strategies.**
